IP Set을 생성하여 허용할 IP 주소를 등록합니다.Web ACL에 Custom Rule을 추가하여 등록된 IP Set 이외의 IP 주소를 차단하도록 설정합니다.허용되지 않은 IP 주소로 접속하면 403 Forbidden 응답을 받게 됩니다.
